## 🎓 教学使用说明

> 本工具是《新闻传播AI应用教程》（中国人民大学出版社）配套在线实验平台工具，属于**篇Ⅲ 实操篇 · 第11章 多媒体与沉浸式新闻**（教材 Tier 1 实验工具）。教材命名："灾前/灾后对比滑块"。

**学习目标**：掌握灾前/灾后滑块对比组件的制作方法，理解"对比"作为视觉修辞的冲击力与伦理边界。

**核心术语**：视觉对比（Visual Comparison）、多媒体叙事（Multimedia Storytelling）、沉浸式报道（Immersive Journalism）

**适合对象**：新闻传播专业学生、视觉编辑、媒体从业者

**课前准备**：准备同一地点的灾前/灾后照片各一张（构图尽量接近；可选用公开卫星图或教学图对，注意版权与伦理）；本工具打开即用、离线可用，照片不上传。

**课堂流程建议（40 分钟，符合教材"单工具课堂可完成"标准）**
1. **演示导入**（8 分钟）：教师上传一组灾前/灾后图对，拖动滑块展示"同一空间、两个时刻"的视觉冲击，并演示两张照片尺寸不一致时工具如何自动缩放对齐
2. **上手实操**（20 分钟）：学生上传一对图片，依次完成：核对两图构图是否对齐、拖动滑块找出信息量最大的分割位置并截图导出、为组件撰写一句规范图注（注明时间、地点、来源）
3. **小组讨论**（8 分钟）：对比滑块天然带情绪冲击，编辑如何避免把灾难"景观化"？使用受灾者财产或遗物画面需要哪些伦理把关？
4. **总结**（4 分钟）：滑块对比是最直观的"变化叙事"，冲击力越强，越需要克制的图注与伦理自查。

**课后作业**：任选一个环境变迁或城市改造主题制作对比滑块作品，配 200 字图注与来源说明。

**评价建议**：实操完成度 40% · 分析深度 40% · 反思质量 20%

> 🔒 本工具所有数据仅在浏览器本地处理，课堂与机房环境可放心使用（支持离线）。
